# Torch Monkey — Python AI mocap pipeline dependencies

# Install CPU-only (dev machine, what we develop against):
#     pip install -r requirements.txt
#
# Install with CUDA (the user's GPU machine). PyTorch wheels are hosted on
# CUDA-specific index URLs. Pick the index that matches your CUDA toolkit, e.g.:
#
#     # CUDA 12.1 (cu121) — most common on modern RTX machines:
#     pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu121
#
#     # CUDA 11.8 (cu118):
#     pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu118
#
#     # Latest CUDA build (auto-detected by torch at runtime):
#     pip install torch --index-url https://download.pytorch.org/whl/cu121
#
# Then install the rest of the pipeline:
#     pip install -r requirements.txt
#
# (requirements.txt pins the CPU torch wheel by default; on the GPU machine,
#  install torch from the CUDA index FIRST so pip does not downgrade it.)
